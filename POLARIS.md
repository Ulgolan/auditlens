=== POLARIS BRIEF (v1.1 — post-Tribunal) ===
Project: AuditLens 2.0
Date: 2026-07-25

GOAL
AuditLens 2.0 is ACP's working audit tool — turning design material into a
client-ready audit with proposal-ready recommendations in a single sitting.
"Proposal-ready" = findings, prioritized recommendations, and a suggested
next-steps section ACP can lift into a real proposal; pricing and commercial
judgment stay human, always.

AUDIENCE / BENEFICIARY
ACP alone, as operator. The client exists only as recipient of an exported
report — export is a mode, not the master. Operator speed beats interface
polish; the export layer absorbs the polish.

NON-NEGOTIABLES
1. Never a silent lie — every report is complete or visibly declares itself
   partial. No grades on truncated audits.
2. One sitting, end to end — material in → audit → proposal-ready output,
   without leaving the tool.
3. Client-exportable without shame — no cleanup pass in another tool, ever.

INPUT SCOPE (ships vs. stretches)
- 2.0 CORE: screenshots + text-described concepts. Both gate the ship.
- STRETCH: gif/video input. Built if the core lands early; never gates.

OUT-OF-SCOPE
- Other users: no accounts, no auth, no multi-tenant, no public launch.
- Auto-implementation: the tool audits and proposes; it never fixes.
- Mobile.
- Automated pricing or commercial terms in any output.
- The polished recruiter case-study as a ship-blocker — raw material is
  captured continuously; publication follows ship, never gates it.

SUCCESS CRITERIA
1. Live-fire: within weeks of shipping, a real target (actual prospect or
   full dry-run on one) goes material → audit → proposal-ready output in
   one sitting — and at least one live-fire run uses TEXT-ONLY input, so
   the concept-audit claim gets tested, not just trusted.
2. Trust: ten consecutive full four-framework audits with zero silent
   truncations — every report complete or self-declaring.

SHIP WINDOW
2.0 core ships this weekend — target 2026-07-25. The anti-shelf clause.
